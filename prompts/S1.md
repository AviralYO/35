# S1: prompts

1. Traversal helper

   > Use the scheme-dev skill and the PDF's built-in whitelist. Can you write a traversal-values helper that takes a tree and an order symbol: inorder, preorder or postorder? Return the value list, visit left subtrees before right ones, and avoid built-in append, reverse or map. A tail-recursive worklist is fine if you explain what it contains.

2. Inorder output

   > Write only print-inorder now. Use the traversal helper to display the inorder list followed by one newline. The empty tree should print () on its own line. Don't call the function at the top level.

3. All traversal output

   > Add print-all-traversals. It should print inorder, preorder and postorder in that order, each on its own line. Use display and newline, with no labels or extra output. Reuse the helper we already have.

4. Tree statistics

   > Can you write a tree-statistics helper that returns the list (height leaf-count)? The empty tree has height 0 and no leaves; a single node has height 1 and one leaf. Keep state in arguments and use only allowed operations. Please make it work sensibly for a long one-sided tree too.

5. Statistics output

   > Add print-height-and-leaves using tree-statistics. It should display exactly the two-number list and a newline, including (0 0) for an empty tree.

6. Test file

   > Write one S1 test file with the balanced number tree, right-skewed tree, symbol tree and empty tree from the handout. Compare the printed text including newlines. Add a single node, a left-skewed tree and a deep tree. For small tree shapes, compare the results with a simple independent recursive reference.

7. Review

   > Review S1 against the Scheme restrictions. Check every built-in used, left-before-right traversal, the empty-tree cases, leaf counting and exact output. Also check that the solution file has only definitions after #lang racket/base and prints nothing when loaded. Explain any problems without rewriting all the functions.
