# S2: prompts

1. Length helper

   > Use the scheme-dev skill. Write only my-length for S2, using the PDF's allowed built-ins. Count top-level elements, so a nested list counts as one element. Make the list walk tail-recursive because the hidden tests can have 10,000 elements.

2. Mapping helper

   > Can you write my-map without using built-in map, reverse or append? Apply the function once to each element, from left to right, and preserve the result order. Use a tail-recursive accumulator and your own restoration loop if needed.

3. Initial insertion function

   > For part b, write insert-if-short using my-length and my-map. Check each list's original length, recursively transform its sublists, and add x at the front when that length is less than n. Include the outer list and empty sublists. Don't process the newly inserted x again.

4. Higher-order inserter

   > Write only make-inserter now. It should take x and a length predicate, then return a function that transforms a nested list. Test each original list's length with that predicate, including empty lists, and use the same rule at every nesting level. It should work with predicates other than less-than.

5. Final insertion definition

   > Refactor just insert-if-short to use make-inserter with a predicate that checks length < n. Replace the earlier definition so the final file contains exactly one insert-if-short definition.

6. Input and output wrapper

   > Add print-insert-result. Read x, then lst, then n from standard input in that exact order. Display the result followed by one newline, without printing prompts. Define the function only; don't call it automatically when the file runs.

7. Test file

   > Write one S2 test file covering all four handout examples. Add n = 0, lengths exactly equal to n, symbol values for x, nested empty lists, and custom predicates for make-inserter. Check that my-map keeps order and calls its function once per element. Include depth 100 and lists of 10,000 elements.

8. Review

   > Review S2 for the original-length rule, empty-list handling and higher-order behavior. Check that insert-if-short has one definition and calls make-inserter, that no forbidden built-ins or mutation are used, and that reading and printing happen only inside the wrapper. Explain any issues you find without replacing the whole solution.
